Your notch,

Isle is a free, open-source Dynamic Island for macOS. It shows music, meetings, AirPods and a file shelf, plus a live view of every AI coding agent you have running.

Get Isle ★ Star on GitHub

Everything at a glance

Hover to open, click to open instantly, swipe with two fingers to switch tabs. Isle blends into the hardware notch, or shows as a pill on displays without one.

Now Playing

Album art, a live visualizer and controls for Spotify and Apple Music. Push-based, so there's no polling.

AI agents

See which agents are working, waiting for you or done, with project and git branch. Click to jump to the agent.

Meetings

Your next events, and a banner five minutes before a meeting starts.

Shelf

Drag files onto the notch to park them, then drag them out wherever you need them.

Devices & battery

Banners when AirPods connect, when you plug in, and when the battery runs low.

HUD

Volume and brightness levels right beside the notch. It can optionally replace the system HUD.

Built for people who live in the terminal

Isle detects coding agents from their process trees, transcripts and optional hooks. It also lists every dev server you started from a project, with open and stop buttons.

Light enough to forget about

The window is never resized, and every animation that stays on screen runs on Core Animation in the render server.

~0% CPU

when closed, even with the visualizer and spinners running.

~1% CPU

with a live activity showing and agents being scanned.

0 dependencies

Pure SwiftUI, AppKit and Core Animation. No telemetry, nothing leaves your Mac.

Install

Build from source in about a minute. Requires macOS 15+ and Xcode 16+.

git clone https://github.com/Felix-Bergmann-Code/isle.git
cd isle
./scripts/build.sh --install --run

Open source, and PRs are welcome

Isle is MIT-licensed. Add support for another agent, a new Now Playing source, or a better icon. Small fixes count too.
